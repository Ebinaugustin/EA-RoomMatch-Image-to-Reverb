# EA-RoomMatch-Image-to-Reverb
EA RoomMatch is an experimental AI reverb plugin that turns room photos into impulse responses. Load or paste an image, generate a reverb, then shape its tone and space. With 100 automatable scene slots, it helps dialogue, film, and post-production sound fit the scene.

These links point directly to release assets and can be used for website download buttons.

Close your DAW before installation. On Windows, extract the entire ZIP and run **Install RoomMatch.cmd**. On macOS, open the installer matching your processor. Mac builds use ad-hoc signatures and are not Apple notarized; the tested hosts were macOS 14 (Apple Silicon) and macOS 15 (Intel).

Packages include VST3, a standalone application, and the offline AI runtime/model. The Mac packages passed native plugin and VST3 checks plus full photo-to-IR generation from an extracted clean runtime. Additional user-machine and DAW testing is needed.
